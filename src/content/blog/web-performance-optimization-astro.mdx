In modern web development, bloated client-side JavaScript bundles are the single biggest cause of poor Core Web Vitals, high Interaction to Next Paint (INP) latency, and degraded Google SEO rankings.

## The Zero-JavaScript-by-Default Paradigm

Astro delivers pure HTML to the browser by default. Interactive UI islands are loaded on-demand only when necessary.

### Performance Benchmarks

| Metric | Traditional SPA / Framework | Astro Static SSG (NI18 Architecture) |
| :--- | :--- | :--- |
| **First Contentful Paint (FCP)** | 1.8s | 0.3s |
| **Largest Contentful Paint (LCP)** | 2.9s | 0.5s |
| **Cumulative Layout Shift (CLS)** | 0.12 | 0.00 |
| **Lighthouse Score** | 68/100 | **100/100** |

```astro
---
// Zero JS shipped to client!
import Header from '../components/Header.astro';
import Footer from '../components/Footer.astro';
---
<Header />
<main>
  <h1>Instant Page Load</h1>
  <p>Static HTML generated at build time.</p>
</main>
<Footer />
```

> [!IMPORTANT]
> Preloading self-hosted web fonts with `font-display: swap` prevents layout shifts and guarantees top Core Web Vitals compliance.
