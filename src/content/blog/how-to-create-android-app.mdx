Building modern Android applications requires a clean separation of concerns, rapid UI iterations, and reliable offline-first data handling. At **NI18**, we design enterprise-grade Android applications engineered for speed, battery efficiency, and long-term maintainability.

## Modern Android Tech Stack

Here is the production-tested architecture we recommend:

1. **Language**: Kotlin 2.x
2. **UI Toolkit**: Jetpack Compose with Material Design 3
3. **Async / Concurrency**: Kotlin Coroutines & StateFlow
4. **Dependency Injection**: Hilt / Koin
5. **Local Database**: Room with SQLite
6. **Networking**: Retrofit2 + OkHttp3 with Kotlin Serialization

```kotlin
@Composable
fun UserProfileScreen(
    viewModel: UserProfileViewModel = hiltViewModel()
) {
    val uiState by viewModel.uiState.collectAsStateWithLifecycle()

    Scaffold(
        topBar = { TopAppBar(title = { Text("NI18 Profile") }) }
    ) { padding ->
        when (val state = uiState) {
            is UiState.Loading -> CircularProgressIndicator()
            is UiState.Success -> ProfileContent(state.user, modifier = Modifier.padding(padding))
            is UiState.Error -> ErrorSnackbar(state.message)
        }
    }
}
```

### Key Architectural Layers

> [!NOTE]
> Adhering to modern Clean Architecture ensures your business logic remains testable and decoupled from Android framework code.

- **UI Layer**: Composable functions rendering immutable UI state.
- **Domain Layer**: Pure Kotlin use cases encapsulating core business rules.
- **Data Layer**: Repositories abstracting local Room databases and remote REST API sources.

## Performance Checklist

To hit 60fps / 120fps smooth scrolling:

- Avoid heavy computations inside `@Composable` recomposition scopes.
- Use `remember` and `derivedStateOf` for derived values.
- Pre-allocate resources and lazy load image bitmaps with Coil.
