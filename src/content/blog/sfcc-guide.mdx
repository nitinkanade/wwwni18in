Salesforce Commerce Cloud (SFCC) powers world-class retail experiences globally. Optimizing B2C storefront performance requires deep knowledge of cartridges, controller pipelines, OCAPI / Shopper APIs, and caching strategies.

## Essential SFCC Development Principles

### 1. Cartridge Pipeline Optimization

Ensure controller execution time remains under 50ms by leveraging custom cache strategies and avoiding heavy SQL queries in rendering loops.

```javascript
'use strict';

var server = require('server');
var cache = require('*/cartridge/scripts/middleware/cache');

server.get('Show', cache.applyDefaultCache, function (req, res, next) {
    var CatalogMgr = require('dw/catalog/CatalogMgr');
    var category = CatalogMgr.getCategory(req.querystring.cgid);
    
    res.render('category/categoryLanding', {
        category: category
    });
    next();
});

module.exports = server.exports();
```

> [!TIP]
> Always enable strict caching headers for static content assets and product detail catalog responses.
