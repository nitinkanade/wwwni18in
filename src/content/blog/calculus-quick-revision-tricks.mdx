## Integration Shortcuts

### Definite Integration Properties
- **King's Property**: `∫[a to b] f(x) dx = ∫[a to b] f(a+b-x) dx`
- **Even/Odd Function Rule**: If `f(-x) = -f(x)`, then `∫[-a to a] f(x) dx = 0`.
